#AlloCiné Movie Reviews : Making a corpus of French-language movie reviews

Where's the data coming from? 
The data comes from Théophile Blard's sentiment analysis GitHub repo : the data we want is here: `https://github.com/TheophileBlard/french-sentiment-analysis-with-bert/blob/master/allocine_dataset/data.tar.bz2`. 
This can be decompressed to a folder `data` in which there is a file `allocine_dataset.pickle` : this is a compressed version of the data  we want, as it contains reviews and movie URLs.

`1_conllise_annocine_reviews.py` takes this pickled file and generates CoNLL-style file that can be passed directly to Stanza for POS-tagging, lemmatisation and dependency parsing.
`2_get_allocine_metadata.py` uses the movie URLS from the first script to scrape the metadata from Allociné, getting the genre, release date, ratings, duration and director name, and stores these in an XML file so they can be added into the metadata of the reviews.
The actual XML file generated by this script is compressed into `allocine_metas.tar.bz2` to save scraping the site again.
